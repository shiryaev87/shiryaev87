## 📁 Пет-проект: Sakura — бронирование земельных участков

Сервис для агентства недвижимости: интерактивная схема участков в SVG, бронирование с сервера, админ-панель управления каталогом. Пишу, чтобы освоить и применить на практике основные инженерные практики Go-разработчика.

**Стек:** Go 1.22+, `net/http` (роутинг с методами и path-параметрами), PostgreSQL, `pgx/pgxpool`, `gorilla/sessions`, `bcrypt`, Docker

**Что уже работает:**

- регистрация и вход: bcrypt для паролей, cookie-сессии
- публичная схема участков — SVG-полигоны с цветовой кодировкой статуса
- бронирование участка с **атомарной проверкой доступности**: условие `status = 'available'` вынесено внутрь `UPDATE`, результат определяется по `RowsAffected()` — двойное бронирование одного участка исключено на уровне запроса
- роли пользователей и middleware авторизации
- админ-панель: список, создание и редактирование участков
- параметризованные запросы везде — SQL-инъекции нет ни в одном обработчике

**В работе:**

- тесты: юнит-тесты бизнес-логики, HTTP-тесты на `httptest`, интеграционные на `testcontainers-go`
- миграции БД (`golang-migrate`) и конфигурация через переменные окружения
- REST API `/api/v1` с DTO, OpenAPI и аутентификацией по JWT
- генератор участков и ETL-загрузка из CSV: worker pool на `errgroup`, каналы, батчевая вставка через `pgx.CopyFrom`
- нагрузочное тестирование (k6), профилирование через `pprof`, метрики Prometheus
